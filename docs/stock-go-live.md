# Stock: ขึ้นเว็บจริงครั้งแรก

เว็บจริงยังเป็น Stock รุ่นแรก (หน้าคลังหน้าเดียว ไอดี 16 ตัวจากชีต 2.1 STOCK_) งานนี้เพิ่ม ใบสั่งซื้อ, กระเป๋าเงิน, ค่าใช้จ่าย, คลังตามชีต, ข้อมูลบัญชี และไฟล์แนบ

## ไม่ต้องเพิ่ม

- **env**: ไม่มีค่าใหม่ที่บังคับ ตารางใหม่สร้างเองตอนเปิดหน้าครั้งแรก (หรือตอนรัน `scripts/stock-go-live-check.mjs`) ตาราง Stock เดิมโครงสร้างตรงกับโค้ดนี้ ใช้ต่อได้เลย
- `STOCK_ATTACHMENTS_DIR` ไม่บังคับ ไม่ตั้งจะเก็บที่ `data/stock-attachments` ในโฟลเดอร์แอป `deploy-server.sh` ไม่ลบโฟลเดอร์ `data/` จึงไม่หายตอน deploy แต่ต้องสำรองโฟลเดอร์นี้คู่กับฐานข้อมูล

## ต้องเตรียม

1. งานต้องอยู่ใน `main` ก่อน (`deploy-server.sh` deploy ได้เฉพาะ commit ใน `origin/main`) · GitHub Action "Deploy main" ถูกปิดไว้ ต้องรันบนเซิร์ฟเวอร์เอง
2. ไฟล์ชีตบัญชีจาก Drive "ข้อมูลบัญชี 2026" (เลือกโฟลเดอร์เดือน → Download แล้วแตก zip) ไฟล์มีข้อมูลการเงินและรหัสในบางช่อง (สคริปต์นำเข้าตัดทิ้ง ไม่เก็บ) อย่าใส่ไว้ใน git และลบออกจากเซิร์ฟเวอร์หลังนำเข้า

## ขั้นตอน

```bash
# 1) จากเครื่องตัวเอง: ส่งไฟล์ชีตขึ้นเซิร์ฟเวอร์
scp -P 48995 account-sheets-2026-01-10.tar.gz root@<server>:/root/

# 2) บนเซิร์ฟเวอร์: deploy main ตามปกติ
/deploy-server.sh

# 3) บนเซิร์ฟเวอร์: แตกไฟล์ แล้วรันขั้นตอน Stock (แต่ละขั้นลองให้ดูก่อน พิมพ์ y ถึงเขียนจริง)
mkdir -p /root/account-sheets && tar -xzf /root/account-sheets-2026-01-10.tar.gz -C /root/account-sheets
cd /www/wwwroot/system.db.inblackm
bash scripts/stock-go-live.sh /root/account-sheets/drive-2026

# 4) ลบไฟล์ชีตออกจากเซิร์ฟเวอร์
rm -r /root/account-sheets /root/account-sheets-2026-01-10.tar.gz
```

`scripts/stock-go-live.sh` ทำตามลำดับ:

0. สำรองตาราง `stock_*` และ `account_sheet_*` ไว้ที่ `data/stock-backup-<เวลา>.sql`
1. เช็คของเดิม ถ้ายังมีรายการคลังจากชีต 2.1 STOCK_ จะถามว่าลบไหม: **ควรลบ** เพราะขั้น 3 สร้างยอดใหม่จากใบสั่งซื้อและยอดนับในชีตบัญชี ถ้าไม่ลบยอดจะนับซ้ำ รายการที่คนกดเองไม่ถูกลบ
2. `import-account-sheets.mjs`: ข้อมูลบัญชี, กระเป๋าเงิน, ค่าใช้จ่าย, คลังตามชีต
3. `import-sheet-inventory.mjs`: ไอดี แพ็ค และใบสั่งซื้อ (ต้องหลังขั้น 2 เพราะผูกใบสั่งซื้อกับรายการจ่ายในกระเป๋า)
4. `link-stock-games.mjs`: ผูกไอดีกับเกมใน GameInfo (ที่ไม่แน่ใจต้องเลือกเองในหน้า ดูไอดีนี้)

รันซ้ำได้: แต่ละขั้นแทนที่เฉพาะแถวที่ตัวเองนำเข้า ของที่คนกรอกยังอยู่ · เดือนใหม่ทำแค่ขั้น 2–3

## หลังขึ้นแล้ว

- เปิด `/stock`, `/stock/purchase-orders`, `/stock/wallets`, `/stock/expenses`, `/stock/sheets`
- หน้าเกมที่มีไอดี stock (เช่น Wuthering Waves) ต้องขึ้นป้าย stock · ชื่อแพ็คที่ขึ้น "ไม่พบใน GameInfo" ในหน้าไอดี ให้แก้ให้ตรงกับหน้าเกม
- ไอดีทุกตัวขึ้นสถานะ "ต้องตรวจ": ชีตไม่มีบันทึกการตัดของออก ต้องนับของจริงแล้วปรับยอดก่อนใช้
- Topup Inventory › จองช่องทาง กลุ่ม "2.1 STOCK" (16 บัญชี) ซ้ำกับคลังใน Stock: ปิดใช้งานหลังถามคนดูแล Topup Inventory
- ตาราง `stock_crypto_addresses` (เมนูที่อยู่โอนที่ลบไปแล้ว) ไม่มีอะไรใช้ ถ้ามีอยู่ลบได้ภายหลัง
