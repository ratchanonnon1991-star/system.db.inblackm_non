# CSV ตัวอย่างสำหรับทดสอบการนำเข้า

ไฟล์ในโฟลเดอร์นี้ใช้ทดสอบการนำเข้า CSV แบบหลายเกม (เมนู **จัดการ CSV → นำเข้า Packs ทุกเกม**
ที่หน้ารายการเกม) ด้วยมือ ครอบคลุมทั้งทางที่ควรผ่านและทางที่ควรถูกปฏิเสธ

ข้อมูลในไฟล์อ้างอิงเกมจริงในฐานข้อมูล dev — `LOVE AND DEEPSPACE` (id 3),
`GODDESS OF VICTORY: NIKKE UID` (id 22), `HONKAI IMPACT` (id 1) ถ้าฐานข้อมูลที่ทดสอบ
ไม่มีเกมเหล่านี้ ให้แก้ `game_id` / `game_name` ในไฟล์ก่อน

## ทดสอบทีละไฟล์

|---|---|

## จุดที่ควรจ้องเป็นพิเศษ

**ไม่มีอะไรถูกสร้างถ้าไม่ติ๊ก** — เกมใหม่และคอลัมน์ใหม่จะขึ้นเป็นรายการให้ติ๊ก
และไม่มีอะไรติ๊กไว้ล่วงหน้า ลองกด **ยืนยันนำเข้า** โดยไม่ติ๊กอะไรเลยดู: เกม/คอลัมน์นั้น
ต้องไม่ถูกสร้าง และแถวของเกมที่ไม่ได้ติ๊กต้องถูกข้ามไปทั้งแถว ไม่ใช่ทำให้ import ล้ม

**ไฟล์ที่มีแต่คอลัมน์ไม่ล้าง packs** (`05`) — ไฟล์แบบนี้ให้ 0 pack กับเกมที่มันเอ่ยถึง
ถ้าเลือกโหมด *แทนที่ packs เดิม* ก็ยังต้องไม่ลบ pack ที่เกมนั้นมีอยู่ ตรวจจำนวน pack
ของเกม 3 (18 packs) และเกม 22 (22 packs) ก่อนและหลังนำเข้าว่าเท่าเดิม

**ค่าในเซลล์เป็นได้ทั้งค่าและสูตร** — ไม่ต้องมีไวยากรณ์พิเศษ ตัวเลขใส่ตรงๆ
ข้อความก็ใส่ตรงๆ และสูตรเขียนแบบที่ใช้ในหน้าแก้ไขได้เลย เช่น `[ราคา] * 1.05`
ถ้าทุกแถวเป็นสูตรเดียวกันระบบจะเสนอยกขึ้นเป็นสูตรของคอลัมน์แทนที่จะใส่ซ้ำทุกแถว

**นำเข้าซ้ำไฟล์เดิม** — ลองนำเข้าไฟล์เดียวกันสองครั้ง ครั้งที่สองคอลัมน์ต้องไม่ขึ้นเป็น
"คอลัมน์ใหม่" อีก เพราะมันถูกลงทะเบียนไปแล้ว และต้องเป็นการเติมค่าลงคอลัมน์เดิมแทน

## ก่อนทดสอบบนฐานข้อมูลที่มีข้อมูลจริง

สำรองฐานข้อมูลก่อน ไฟล์เหล่านี้เขียนข้อมูลจริงทั้งหมด และโหมด *แทนที่ packs เดิม*
จะแทน packs ของเกมที่ไฟล์เอ่ยถึงจริงๆ (ยกเว้นกรณี `05` ข้างบน)
