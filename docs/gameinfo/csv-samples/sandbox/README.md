# ชุดทดสอบ CSV แบบไม่แตะข้อมูลจริง (sandbox)

ต่างจากไฟล์ใน `../` ตรงที่ชุดนี้ **สร้างเกมของตัวเอง** (`CSVTEST ALPHA/BETA/GAMMA/DELTA`)
จึงรันซ้ำได้เรื่อย ๆ และไม่ทับ pack ของเกมจริง ใช้กับเมนู **จัดการ CSV** ที่หน้ารายการเกม

> คอลัมน์ที่ชุดนี้สร้างเป็น **ของกลางทุกเกม** (column registry) — ชื่อคอลัมน์จึงลงท้ายด้วย
> "ทดสอบ" ทุกตัว เพื่อให้ลบทิ้งทีหลังได้โดยไม่สับสนกับคอลัมน์งานจริง

## ลำดับการโหลด

| ขั้น | ไฟล์ | เมนู | โหมด |
|---|---|---|---|
| 1 | `00-seed-games.csv` | เพิ่มเกมด้วย CSV | — |
| 2 | `01-seed-packs.csv` | นำเข้า Packs ทุกเกม | แทนที่ |
| 3 | ไฟล์ `02`–`13` ตามที่อยากทดสอบ | นำเข้า Packs ทุกเกม | ตามตารางข้างล่าง |

**`01-seed-packs.csv` คือปุ่มรีเซ็ต** — โหลดซ้ำด้วยโหมด *แทนที่* เมื่อไหร่ก็ได้
เพื่อกลับไปที่ pack ตั้งต้น 6 แพ็ก (ALPHA 3, BETA 2, GAMMA 1)
แต่ *คอลัมน์* ที่สร้างไปแล้วไม่ถูกลบ — ดูหัวข้อ "ล้างของทดสอบ" ท้ายไฟล์

## ที่ต้องจ้องเป็นพิเศษ

1. **สูตรในไฟล์เป็นของเกมที่ไฟล์เอ่ยถึงเท่านั้น** (`03`) — ใส่สูตรไว้แค่แถวของ ALPHA
   แล้วนำเข้า → เปิดเกมอื่นต้องไม่มีค่าในคอลัมน์นี้ และหน้าแก้คอลัมน์ของ ALPHA ต้องขึ้นว่า
   **สูตรเฉพาะเกม** — ไม่ใช่ "สูตรหลัก"
2. **สองเกมใส่สูตรต่างกันในคอลัมน์เดียวกันได้** (`04`) — ALPHA ต้องได้ `*0.10`
   และ BETA ได้ `*0.25` ต่างคนต่างเก็บ หน้า preview จะบอกว่า "ใช้สูตรต่างกันตามเกม"
3. **สลับลำดับแถวในไฟล์แล้วผลต้องเท่าเดิม** — เอา `04` มาสลับให้แถว BETA อยู่บน
   แล้วนำเข้าใหม่ — ทั้งสองเกมต้องได้สูตรของตัวเองเหมือนเดิม
4. **นำเข้าไฟล์เดิมซ้ำ** — ครั้งที่สองคอลัมน์ต้องไม่ขึ้นเป็น "คอลัมน์ใหม่" อีก
5. **โหมดแทนที่ไม่ล้างเกมที่ไฟล์ไม่ได้เอ่ยถึง** และไม่ล้างเกมที่ไฟล์เอ่ยถึงแต่ไม่มี pack (`05`)

## ล้างของทดสอบ

ลบคอลัมน์ที่สร้างไว้ได้จากหน้า packs ของเกมไหนก็ได้ (คอลัมน์เป็นของกลาง ลบครั้งเดียวหายทุกเกม)
ส่วนเกมทดสอบลบได้จากหน้าจัดการเกม ถ้าจะล้างจาก SQL ให้ลบ
`gamelist_pack_column_registry` เฉพาะ `label LIKE '%ทดสอบ'` และ `game_list` ที่ `game LIKE 'CSVTEST %'`
พร้อมแถวใน `gamelist_packs` / `gameinfo_mode_data` ของ game_id เหล่านั้น
