# Stock: ขึ้นเว็บจริง

เว็บจริงยังเป็น Stock รุ่นแรก (หน้าคลังหน้าเดียว ไอดี 16 ตัวจากชีต 2.1 STOCK_) งานนี้เพิ่ม ใบสั่งซื้อ, กระเป๋าเงิน, ค่าใช้จ่าย, คลังตามชีต, ข้อมูลบัญชี, ไฟล์แนบ และซิงค์ชีตบัญชีจาก Drive

## คน deploy: deploy ตามปกติ ไม่มีขั้นพิเศษ

- ไม่มี env ใหม่ที่บังคับ ตารางใหม่สร้างเองตอนเปิดหน้าครั้งแรก ตาราง Stock เดิมใช้ต่อได้ (โครงสร้างตรงกัน)
- ซิงค์จาก Drive ใช้ key ตัวเดียวกับงาน iTune: `ITUNE_SHEETS_CREDENTIALS` (ถ้าเว็บจริงตั้งไว้แล้วไม่ต้องทำอะไร)
- ไม่บังคับ: `ACCOUNT_SHEETS_DRIVE_FOLDER` (id หรือลิงก์โฟลเดอร์) ถ้าเปลี่ยนโฟลเดอร์ ค่าเริ่มต้นคือ "ข้อมูลบัญชี 2026"
- ไม่บังคับ: `STOCK_ATTACHMENTS_DIR` ไม่ตั้งจะเก็บไฟล์แนบที่ `data/stock-attachments` (`deploy-server.sh` ไม่ลบ `data/`) ต้องสำรองโฟลเดอร์นี้คู่กับฐานข้อมูล

## เจ้าของงาน: หลังขึ้นเว็บแล้ว ครั้งเดียว

1. เปิด Stock › ข้อมูลบัญชี › **ซิงค์จาก Drive** หน้าต่างจะบอก email ของ service account
2. แชร์โฟลเดอร์ Drive "ข้อมูลบัญชี 2026" ให้ email นั้น สิทธิ์ **ผู้มีสิทธิ์อ่าน** (Viewer)
3. กด **ลองดูก่อน**: โหลดไฟล์ทุกเดือนแล้วบอกว่าจะเข้ามาเท่าไร (ยังไม่เขียน)
4. กด **ซิงค์และนำเข้า**: ทำครบทุกขั้น
   - ลบยอดคลังเก่าจากชีต 2.1 STOCK_ (ถ้าไม่ลบ ยอดคงเหลือจะนับซ้ำกับยอดที่สร้างจากใบสั่งซื้อและยอดนับ) รายการที่คนกดเองไม่ถูกลบ
   - ชีตบัญชี → ข้อมูลบัญชี, กระเป๋าเงิน, ค่าใช้จ่าย, คลังตามชีต
   - ไอดี แพ็ค และใบสั่งซื้อจากชีต → คลัง, ใบสั่งซื้อ
   - ผูกไอดีกับเกมใน GameInfo เฉพาะที่แน่ใจ (ที่เหลือเลือกเองในหน้า ดูไอดีนี้)

เดือนใหม่: ฝ่ายบัญชีเพิ่มโฟลเดอร์ "ข้อมูลบัญชี M-YYYY" ใน Drive แล้วกด ซิงค์และนำเข้า อีกครั้ง นำเข้าซ้ำได้เสมอ แต่ละส่วนแทนเฉพาะข้อมูลที่มาจากชีต ของที่คนกรอกในเว็บยังอยู่ (ยกเว้นใบสั่งซื้อจากชีตที่มีไฟล์แนบแล้ว: ระบบจะหยุดและบอก)

ถ้าขึ้นข้อผิดพลาด หน้าต่างจะบอกสาเหตุ: ยังไม่แชร์โฟลเดอร์ (404), ยังไม่เปิด Google Drive API ใน project ของ service account (403), หรือไฟล์ key ใช้ไม่ได้

## ทางสำรอง (บนเซิร์ฟเวอร์)

```bash
cd /www/wwwroot/system.db.inblackm
node scripts/sync-account-sheets.mjs            # ลองดูจาก Drive
node scripts/sync-account-sheets.mjs --apply    # นำเข้าจาก Drive
node scripts/sync-account-sheets.mjs --from "<โฟลเดอร์ที่มี ข้อมูลบัญชี M-YYYY>" --apply   # จากไฟล์บนเครื่อง
node scripts/stock-go-live-check.mjs            # ดูว่ามีอะไรอยู่ (อ่านอย่างเดียว)
```

ไฟล์ชีตที่โหลดมาเก็บใน `data/account-sheet-sync/run-<id>` ระหว่างรันเท่านั้น จบแล้วลบทิ้ง

## หลังนำเข้าแล้ว

- เปิด `/stock`, `/stock/purchase-orders`, `/stock/wallets`, `/stock/expenses`, `/stock/sheets`
- หน้าเกมที่มีไอดี stock (เช่น Wuthering Waves) ต้องขึ้นป้าย stock · ชื่อแพ็คที่ขึ้น "ไม่พบใน GameInfo" ในหน้าไอดี ให้แก้ให้ตรงกับหน้าเกม
- ไอดีทุกตัวขึ้นสถานะ "ต้องตรวจ": ชีตไม่มีบันทึกการตัดของออก ต้องนับของจริงแล้วปรับยอดก่อนใช้
- Topup Inventory › จองช่องทาง กลุ่ม "2.1 STOCK" (16 บัญชี) ซ้ำกับคลังใน Stock: ปิดใช้งานหลังถามคนดูแล Topup Inventory
- ตาราง `stock_crypto_addresses` (เมนูที่อยู่โอนที่ลบไปแล้ว) ไม่มีอะไรใช้ ลบได้ภายหลัง
